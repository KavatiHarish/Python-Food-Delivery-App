# 🍔 Python Food Delivery App

## 📌 Project Overview

This is a Console-Based Food Delivery Application developed using Python.

The project was built independently using Python Lists and basic programming concepts without using databases or frameworks.

It simulates the workflow of an online food delivery application with separate Owner and User panels.

---

## 🚀 Features

### 👨‍💼 Owner Panel

- View Restaurants
- Add Restaurants
- Remove Restaurants
- Modify Restaurant Names
- Add Menu Items
- Remove Menu Items
- Modify Menu Items
- View Orders
- Generate Reports

---

### 👤 User Panel

- User Login
- Browse Restaurants
- View Menu
- Add Items to Cart
- View Cart
- Apply Coupon
- Payment Options
- Order Confirmation
- Order Tracking
- Order History
